### Guia de Uso – Sistema de Aconselhamento Médico

Muitas pessoas recorrem a buscas na internet quando se sentem doentes, não por ignorância, mas por desespero diante de um sistema de saúde que frequentemente fecha as portas para quem não tem cartão de crédito. Este sistema foi criado para atenuar, ainda que minimamente, essa desigualdade, oferecendo de forma ética e responsável um aconselhamento inicial, confiável e acessível. Não porque somos melhores, mas porque somos iguais.

Também desenvolvemos um dicionário e buscamos adaptar tudo para uma linguagem acessível, cansados do excesso de tecnicismo que limita o entendimento real da situação.

Este sistema existe para ajudar você a entender melhor seus sintomas antes de buscar atendimento. Ao final do aconselhamento principal, você receberá uma cor de gravidade com uma legenda de próximos passos. Porém, o sistema se manifesta ao longo de todo o processo, não apenas no resultado final — leia as mensagens intermediárias para uma experiência mais completa.

**Como usar (passo a passo)**
1. **Formulário inicial** – Preencha seus dados corretamente. Não guardamos suas informações; o objetivo é apenas compreender melhor o quadro clínico.
2. **Autotestes** – Use a aba lateral para confirmar sintomas suspeitos e fazer um check-up simples.
3. **Seleção de sintomas** – Escolha até 3 sintomas principais.
4. **Detalhamento** – Responda honestamente às perguntas sobre cada sintoma.
5. **Resultado** – Veja a cor de cada sintoma e a cor final do quadro geral, com explicação dos motivos.

**Recursos**
- **Dicionário de sintomas**: explicações técnicas e em linguagem acessível, incluindo termos usados no detalhamento.
- **Autotestes**: testes simples para investigar sinais do corpo em casa.
- **Aconselhamento principal**: seleção de sintomas, perguntas dirigidas e cor de atenção, com instruções de próximos passos.

**Observações importantes**
- No celular, consulte o dicionário antes de escolher sintomas. A seleção manual no mobile funciona melhor digitando o sintoma; use o dicionário para garantir que o termo está correto.
- No menu lateral há três opções: “Nenhuma”, “Dicionário de sintomas” e “Autotestes para apuração de sintomas”. Se selecionar “Nenhuma”, a tela fica livre para o aconselhamento principal. As outras opções aparecem no topo da tela e o aconselhamento segue abaixo.
- Os autotestes só ficam disponíveis após preencher o formulário inicial, pois os dados são usados em cálculos.
- O sistema **não guarda** dados pessoais; tudo ocorre localmente durante o uso.

**Aviso importante**
Este sistema **não substitui consulta médica**. Em caso de dúvida, procure um profissional.
